# Quick Start

1. Extract the ZIP.
2. Open the folder in VS Code.
3. Put the MetroPT-3 raw data file inside `data/raw/`.
4. Run `setup_windows.bat`.
5. Open `notebooks/01_data_audit.ipynb`.
6. Select kernel `Python (FYP MetroPT)`.
7. Run the notebook from top to bottom.

Do not upload the raw dataset to GitHub.
